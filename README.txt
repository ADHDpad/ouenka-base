正式ジャッキ仕様
- BPM 170 / 4拍子
- 1小節 = 1.41176470588秒
- 前曲の9小節目の頭に、次曲の1小節目の頭を重ねる
- 開始間隔 = 8小節 = 11.2941176471秒
- 次曲1小節目が空白でも削らず、そのまま1小節として扱う
- 前曲9小節目と次曲1小節目の両方の音を残す
- クロスフェードなし
- 曲別の固定ゲイン補正なし
- 前曲・次曲の重複音は両方とも保持
- 重なりで音量が上がった瞬間だけ最終ミックスを自動調整
- リミット値 ±0.98 / リリース約70ms
- 重なり終了後は自然に元の音量へ復帰
- 旧SmartOverlap（曲別に一律で下げる方式）は使用しない

音源選択
- 1曲目：通常再生用 m4a
- 2曲目以降：メドレー用 m4a

画面表示
- 通常の再生中・作成中・停止・再生終了メッセージは画面下部に表示しない
- 音源取得失敗などのエラーメッセージは表示する
