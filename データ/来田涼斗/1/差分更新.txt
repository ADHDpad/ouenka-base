【音源更新の手順】
1. このZIPを展開してください。
2. 中の変更ファイルを、GitHub Desktopで管理している対象選手の公開フォルダへコピーし、同名ファイルを上書きしてください。
3. GitHub DesktopでCommit→Push originしてください。
4. GitHub Pagesの公開後に再生を確認してください。

古いファイルを事前に削除する必要はありません。

重要：この画面の『更新』は選手情報のAPI更新と端末内データ更新です。GitHub公開音源の上書きは自動ではありません。
GarageBand ZIP/MIDIだけ変更しても、再生に使うaccompaniment.m4aは自動生成されません。伴奏を変更した場合は新しいaccompaniment.m4aも一緒に指定してください。
同じ端末の旧キャッシュが残る場合は再読み込みしてください。
